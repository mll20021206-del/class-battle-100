# 班级大作战（最多100人）

一个适合课堂展示的多人实时互动网页游戏。老师电脑创建房间并显示二维码，同学用微信扫码后直接在浏览器加入。

## 功能
- 最多100人加入同一房间
- 微信扫码打开网页
- 昵称加入
- 红/蓝队自动分队
- 5轮课堂互动题
- 实时作答人数
- 实时个人/团队积分
- 最终排行榜
- Socket.IO 实时通信

## 本机运行
1. 安装 Node.js 18 或更高版本。
2. 在项目文件夹打开终端。
3. 执行：
   npm install
4. 再执行：
   npm start
5. 电脑浏览器打开：
   http://localhost:3000

注意：localhost 生成的二维码只适合本机演示，手机无法通过公网访问。

## 真正让全班微信扫码
需要把这个项目部署到一个支持 Node.js + WebSocket 的公网服务器/托管平台，并设置：
PUBLIC_URL=https://你的公网域名

之后打开公网主页创建房间，二维码会自动指向公网学生页面。

## 课堂使用
1. 老师打开主持端主页。
2. 点击“创建课堂房间”。
3. 投影二维码。
4. 同学微信扫码、输入昵称。
5. 等待人数到齐，点击“开始游戏”。
6. 每轮结束后老师点击“下一题”。
7. 最后一轮结束后自动显示排行榜。

## AI扩展
